# 리스테리아 검출 예측 모델 성능 개선 실험 계획서

## 1. 연구 목적 및 데이터 특성

### 1.1 연구 목적

- 과거 10년간의 식품 수거·검사 데이터와 기후 시계열 데이터를 활용하여 리스테리아 검출 여부를 예측한다.
- 극심한 클래스 불균형 상황에서 검출 성능을 개선한다.
- 품목별 검출 이력, 제품명 텍스트, 지역 특성 및 과거 기후 패턴의 예측 효과를 검증한다.
- 정형 데이터와 시계열 데이터를 결합하는 최적의 모델 구조를 탐색한다.
- 지도학습과 비지도 이상 탐지 모델의 성능을 비교한다.

### 1.2 데이터 구성

**① 수거·검사 정형 데이터**

- 수거 일자
- 지역 정보: 시도, 시군구, 위도, 경도 등
- 식품 품목 및 품목 분류
- 제품명 및 제품명에서 추출한 텍스트 피처
- 검사 결과: 검출(1), 불검출(0)

**② 기후 시계열 데이터**

- 각 수거일을 기준으로 과거 100일의 기후 데이터
- 주요 변수: 온도, 강수량, 일조량 등
- 추가 후보: 토양 수분, 수질 관련 변수 등
- 데이터 구조: `(검사 건수, 100일, 기후 변수 개수)`

### 1.3 핵심 문제

- 검출률이 약 0.3% 수준으로 매우 낮다.
- 검출 사례가 전체 약 200개 품목 중 상위 10~20개 품목에 집중된다.
- 클래스 가중치, 부스팅, 앙상블 등의 방법만으로는 성능 개선에 한계가 있다.
- 제품명 텍스트 마이닝을 통해 피처를 추가했을 때 일부 성능 개선이 관찰되었다.

## 2. 전체 실험 전략

실험은 다음 순서로 진행한다.

| 단계 | 실험 내용 | 목적 | 우선순위 |
|---|---|---|---|
| 1 | 데이터 분할 및 기준 모델 재검증 | 비교 기준 확보 | 최우선 |
| 2 | 스무딩 타깃 인코딩 | 품목별 과거 검출 위험도 반영 | 최우선 |
| 3 | 과거 검사 건수 및 로그 변환 | 품목별 표본 수와 불확실성 반영 | 높음 |
| 4 | 최근 검출률 및 WOE 비교 | 시간적 변화와 대안 인코딩 검증 | 높음 |
| 5 | 상위 검출 품목군 분리 모델 | 검출 사례 집중 현상 활용 | 높음 |
| 6 | 기후 시계열 입력 방식 비교 | 시계열의 추가 예측력 검증 | 중간 |
| 7 | 정형 데이터와 시계열 딥러닝 결합 | 모달리티별 패턴 학습 | 중간 |
| 8 | 오토인코더 및 VAE 이상 탐지 | 정상 패턴에서 벗어난 사례 탐지 | 후순위 |

## 3. 1단계: 데이터 분할 및 기준 모델 확보

### 3.1 데이터 분할

- 학습 데이터: 과거 기간
- 검증 데이터: 학습 데이터보다 이후 기간
- 테스트 데이터: 가장 최근 기간

예를 들어, 전체 10년 데이터를 7년 학습, 1년 검증, 2년 테스트로 나눌 수 있다. 단, 실제 검출 건수와 연도별 분포를 확인한 뒤 분할 기간을 확정한다.

### 3.2 데이터 누수 방지

- 각 검사 건의 과거 이력 피처는 해당 검사일 이전의 정보만 사용한다.
- 타깃 인코딩 계산에 현재 검사 건이나 미래 검사 결과를 포함하지 않는다.
- 학습 데이터의 인코딩 통계와 테스트 데이터의 인코딩 통계를 구분한다.
- 동일 제품이나 동일 수거 건에서 파생된 데이터가 학습·테스트에 중복되는지 점검한다.
- 기후 변수는 수거일 당일까지 실제로 이용 가능한 데이터만 사용한다.

### 3.3 기준 모델

- 모델: 기존 XGBoost
- 입력: 현재 사용하는 정형 피처와 제품명 텍스트 피처
- 기록 지표:
  - PR-AUC
  - Recall
  - Precision
  - F1-score
  - TP, FP, FN, TN
  - 실제 검출 건수 중 포착한 건수

이 모델을 모든 후속 실험의 기준선으로 사용한다.

## 4. 2단계: 품목별 과거 검출 이력 피처 엔지니어링

### 4.1 스무딩 타깃 인코딩

품목별 검사 건수와 검출 건수를 활용하여 과거 검출률을 계산한다.

#### 산술식

- \(n_i\): 품목 \(i\)의 과거 검사 건수
- \(s_i\): 품목 \(i\)의 과거 검출 건수
- \(p_0\): 전체 과거 데이터의 검출률
- \(k\): 스무딩 조정 계수

\[
TE_i=\frac{s_i+k p_0}{n_i+k}
\]

#### 예시

전체 검출률이 0.3%이고 \(k=100\)이라고 가정한다.

| 품목 | 검사 건수 | 검출 건수 | 원래 검출률 | 스무딩 검출률 |
|---|---:|---:|---:|---:|
| A | 10 | 1 | 10% | 약 1.18% |
| B | 100 | 10 | 10% | 약 5.27% |
| C | 1,000 | 100 | 10% | 약 9.12% |

검사 건수가 적은 품목은 전체 평균에 더 가깝게 보정하고, 검사 건수가 많은 품목은 실제 검출률을 더 많이 반영한다.

※ 위 예시는 전체 검출률 0.3%가 해당 과거 기준 데이터에서 계산되었다고 가정한 단순 예시이다.

#### 실험 항목

- `smoothed_rate_5y`: 과거 5년 스무딩 검출률
- `smoothed_rate_1y`: 과거 1년 스무딩 검출률
- 스무딩 계수 \(k\): 10, 30, 50, 100, 200 비교
- 전체 평균 검출률은 반드시 각 예측 시점 이전 데이터로 계산한다.

### 4.2 과거 검사 건수 피처

품목별 표본 규모 자체도 모델에 입력한다.

- `count_5y`: 과거 5년 검사 건수
- `log_count_5y`: 과거 5년 검사 건수의 로그 변환
- `count_1y`: 과거 1년 검사 건수

로그 변환식은 다음과 같다.

\[
\text{log\_count\_5y}=\log(1+\text{count\_5y})
\]

검사 건수의 범위가 넓을 때 큰 값의 영향을 줄일 수 있다.

### 4.3 최근 검출률과 장기 검출률 비교

다음 피처를 단계적으로 추가한다.

- `smoothed_rate_5y`: 장기적인 품목 위험도
- `smoothed_rate_1y`: 최근 품목 위험도
- `count_5y`: 장기 검사 규모
- `count_1y`: 최근 검사 규모
- `log_count_5y`: 장기 검사 규모의 로그 변환

검출률과 검사 건수는 서로 다른 정보를 제공하므로, 처음부터 모두 추가하기보다 단계별로 성능을 비교한다.

### 4.4 WOE(Weight of Evidence) 비교

WOE는 범주별 검출군과 불검출군의 상대적 분포 차이를 수치화하는 방법이다.

일반적인 정의는 다음과 같다.

\[
WOE_i=\ln\left(
\frac{P(\text{불검출}\mid i)}
{P(\text{검출}\mid i)}
\right)
\]

실제 구현에서는 클래스 비율의 정의에 따라 분자·분모가 반대로 쓰이기도 한다. 따라서 방향을 일관되게 정해야 한다.

- 품목별 WOE를 계산한다.
- 극소수 검출 품목에서 무한대가 발생하지 않도록 스무딩을 적용한다.
- 검출 건수가 너무 적은 품목은 별도 범주로 묶거나 추정치를 보정한다.
- 스무딩 타깃 인코딩과 WOE를 동일한 시간 분할에서 비교한다.

WOE는 은행권 신용평가에서 널리 활용되는 기법이지만, 리스테리아 검출 예측에서 반드시 더 우수한 것은 아니다.

## 5. 3단계: 품목군 분리 모델

검출 사례가 상위 10~20개 품목에 집중된다는 특성을 활용한다.

### 실험 A: 전체 품목 모델

- 모든 품목을 포함한다.
- 기존 XGBoost와 동일한 방식으로 학습한다.
- 전체 데이터에 대한 예측 성능을 측정한다.

### 실험 B: 상위 검출 품목 전용 모델

- 학습 데이터에서 검출 사례가 집중된 상위 품목군을 선정한다.
- 해당 품목군에 대해서만 모델을 학습한다.
- 동일한 품목군의 테스트 데이터에서 성능을 평가한다.

### 실험 C: 전체 품목 + 품목 위험도 피처

- 전체 품목을 유지한다.
- 스무딩 검출률, 검사 건수, 제품명 피처를 추가한다.
- 전체 모델의 성능을 측정한다.

### 비교 시 주의사항

- 상위 품목군 선정 기준은 학습 데이터만으로 결정한다.
- 전체 품목 모델과 상위 품목 전용 모델의 성능을 비교할 때는 동일한 평가 대상에 대한 결과를 별도로 제시한다.
- 상위 품목군에서 성능이 좋아져도 전체 식품 검사 데이터의 성능이 개선되었다고 단정하지 않는다.
- 실제 운영 시 상위 품목 외의 검출 사례를 놓칠 가능성도 평가한다.

## 6. 4단계: 기후 시계열 데이터 활용

기후 데이터는 검사 시점의 정형 데이터와 별도로 구성된 과거 100일 시계열이다.

### 실험 A: 정형 데이터만 사용

- 품목, 지역, 제품명, 과거 검출 이력 등을 사용한다.
- 모델: XGBoost

### 실험 B: 시계열을 펼쳐 정형 피처로 변환

- 100일 × 기후 변수 수를 하나의 긴 피처 벡터로 변환한다.
- 정형 데이터와 결합해 XGBoost에 입력한다.
- 데이터 차원이 지나치게 커지는지 확인한다.

### 실험 C: 시계열 요약 피처 추가

- 과거 100일 평균
- 표준편차
- 최솟값·최댓값
- 최근 7일·30일·100일 평균
- 추세 및 변동성 지표

요약 피처를 정형 데이터에 추가해 성능을 비교한다.

### 실험 D: 시계열 딥러닝 모델

- 입력: `(batch, 100, climate_features)`
- 후보 모델: TCN, LSTM
- 기후 시계열에서 시간적 패턴을 학습한다.

---

## 7. 5단계: 정형 데이터와 시계열 데이터 결합

### 방식 A: 단일 모델 입력

정형 데이터와 펼친 시계열 데이터를 하나의 피처 벡터로 결합해 XGBoost에 입력한다.

### 방식 B: 딥러닝 특징 결합(Concatenation)

각 데이터 유형에 별도의 인코더를 적용한다.

- 정형 데이터 → MLP
- 기후 시계열 → TCN 또는 LSTM
- 두 모델의 중간 표현 벡터를 결합
- 결합 벡터 → 최종 분류층
- 출력: 리스테리아 검출 확률

개념적 구조:

`정형 데이터 → MLP ─────────┐`

`                         ├→ Concatenate → 분류층 → 검출 확률`

`기후 시계열 → TCN/LSTM ───┘`

### 방식 C: 스태킹(Stacking)

- 1차 모델: 정형 데이터 기반 XGBoost
- 2차 모델: 기후 시계열 기반 TCN/LSTM 또는 별도 모델
- 메타 모델: 1차 모델의 예측값과 2차 모델의 예측값을 결합

스태킹의 메타 학습 데이터는 반드시 시간 순서를 지킨 out-of-fold 예측값으로 만들어야 한다. 학습 데이터에 대한 모델의 예측값을 그대로 사용하면 과적합과 데이터 누수 위험이 있다.

### 권장 비교 순서

1. 정형 데이터 XGBoost
2. 정형 데이터 + 시계열 요약 피처 XGBoost
3. 정형 데이터 MLP + 기후 시계열 TCN/LSTM 결합
4. XGBoost와 시계열 모델의 스태킹

## 8. 6단계: 오토인코더와 VAE 기반 이상 탐지

검출 사례가 극소수라는 점을 고려해 비지도 이상 탐지 모델도 비교한다.

### 8.1 일반 오토인코더(AE)

- 정상 데이터 중심으로 학습한다.
- 입력 데이터를 복원하도록 학습한다.
- 입력과 복원값의 차이를 이상 점수로 계산한다.

\[
AnomalyScore(x)=\|x-\hat{x}\|^2
\]

### 8.2 베리에이셔널 오토인코더(VAE)

- 입력 데이터의 잠재 분포를 학습한다.
- 재구성 오차 또는 잠재 분포 관련 점수를 이용해 이상 여부를 평가한다.
- 일반 오토인코더와 동일한 테스트 데이터에서 비교한다.

### 8.3 권장 실험

- AE 이상 점수만으로 검출 여부를 예측한다.
- VAE 이상 점수만으로 검출 여부를 예측한다.
- AE 또는 VAE 이상 점수를 기존 XGBoost 피처에 추가한다.
- 지도학습 모델 단독 결과와 결합 모델 결과를 비교한다.

**주의사항**

정상 데이터에서 벗어나는 패턴이 반드시 리스테리아 검출을 의미하지는 않는다. 따라서 이상 점수의 PR-AUC와 Recall을 실제 검출 라벨로 검증해야 한다.

## 9. 평가 지표 및 비교 기준

검출률이 약 0.3%인 상황에서는 Accuracy만으로 모델 성능을 판단하지 않는다.

| 지표 | 의미 | 활용 목적 |
|---|---|---|
| PR-AUC | 정밀도와 재현율의 관계를 종합 평가 | 핵심 성능 지표 |
| Recall | 실제 검출 사례 중 찾아낸 비율 | 검출 누락 감소 |
| Precision | 검출 예측 중 실제 검출 비율 | 불필요한 추가 검사 관리 |
| F1-score | Precision과 Recall의 조화평균 | 균형 비교 |
| TP | 실제 검출을 검출로 예측 | 포착 건수 |
| FP | 불검출을 검출로 예측 | 오탐 건수 |
| FN | 실제 검출을 놓친 건수 | 미검출 위험 |
| Top-k Recall | 상위 위험 예측 건에서 실제 검출을 포착한 비율 | 검사 우선순위 결정 |

### 평가 시 주의사항

- 모든 모델을 동일한 테스트 기간과 동일한 평가 대상에서 비교한다.
- PR-AUC는 임계값과 무관한 지표로 기록한다.
- Recall, Precision, F1-score는 검증 데이터에서 정한 임계값을 사용한다.
- 실제 검사 자원이 제한되어 있다면 상위 1%, 5%, 10% 위험군의 검출 포착률을 추가로 계산한다.
- 클래스 가중치나 오버샘플링을 적용했다면 그 설정을 별도로 기록한다.

## 12. 최종 권고

가장 먼저 확인해야 할 것은 더 복잡한 모델의 도입 여부가 아니라, **품목별 과거 검출 이력이 기존 모델에 새로운 예측 정보를 제공하는지**이다.

따라서 다음 순서로 진행한다.

1. 기존 XGBoost 기준 성능 확보
2. 스무딩 타깃 인코딩 추가
3. 로그 검사 건수와 최근 검출률 추가
4. WOE 및 품목군 분리 모델 비교
5. 기후 시계열 요약 피처와 딥러닝 결합
6. AE/VAE 이상 탐지 점수의 추가 효과 검증

모든 실험은 동일한 시간순 테스트 데이터에서 평가한다. 실제 검출률이 낮으므로 PR-AUC와 Recall을 핵심 지표로 삼되, 오탐 건수와 검사 자원 대비 포착률도 함께 확인한다.

**최종 목표는 특정 지표 하나를 높이는 것이 아니라, 실제 검사 환경에서 제한된 검사 자원으로 더 많은 리스테리아 검출 사례를 포착할 수 있는 모델을 찾는 것이다.**
